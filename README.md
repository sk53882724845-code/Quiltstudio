# Pixora Studio — website starter

A responsive static website starter for a small creative-design studio.

## Included
- Home, Services, Work, About and Contact pages
- Three original educational guides
- Starter Privacy Policy, Terms and Disclaimer pages
- Responsive navigation and CSS styling
- Demo contact form that opens an email draft (no server-side collection)
- 404 page, robots.txt and sitemap.xml

## Before publishing
1. Replace `hello@pixorastudio.example` in `contact.html` and `assets/js/main.js` with an email address you are authorised to use and actively monitor.
2. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` with your real domain.
3. Review every policy page and fill in the bracketed details. These are templates, not legal advice.
4. Replace sample portfolio concepts only with genuine work you created or have permission to show. Keep concepts clearly labelled.
5. Test every page on a phone and desktop.
6. Add real contact, pricing and delivery details only after they are decided and can be honoured.
7. Do not add ads to empty pages, contact success states, admin pages or other screens without meaningful publisher content. This starter intentionally contains no ad code.

## Contact form note
The form uses `mailto:` and does not store submissions. It depends on the visitor having an email app configured. For a production form, use a reputable form provider only after reviewing its privacy terms and adding accurate disclosures.

## GitHub Pages
Upload the contents of this folder to the root of a GitHub Pages repository. Do not upload the outer ZIP file as the website itself; extract it first.
